# DDYA - Portafolio de trabajos

El contenido de este indice corresponde a los archivos versionados en la rama `Semana-8`.

## Formatos encontrados

- **Python (`.py`)** para ejercicios ejecutables desde consola.
- **Jupyter Notebook (`.ipynb`)** para laboratorios con explicacion, analisis, diagramas, codigo y pruebas.
- **PowerPoint (`.pptx`)** y **PDF (`.pdf`)** para presentaciones de apoyo.

## Como ejecutar o revisar los trabajos

1. Abrir los notebooks `.ipynb` con Jupyter Notebook, JupyterLab, Google Colab o Visual Studio Code.
2. Ejecutar el archivo de Python de la Semana 1 con:

   ```bash
   python DDYA/SEMANA_1/prueba_tecnica.py
   ```

3. Revisar las presentaciones `.pptx` y `.pdf` desde el visor correspondiente.
